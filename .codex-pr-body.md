## Resumo
- adiciona filtros publicos de preco minimo, preco maximo e raio minimo de atendimento
- permite ordenar fotografos por recomendacao, preco, raio de atendimento ou atualizacao recente
- mantem paginacao e privacidade dos perfis nao publicados, com parametros SQL e ordenacao em allowlist
- adiciona indices D1 para preco e raio, interface responsiva, traducoes PT/EN e contratos automatizados

## Validacao
- `npm test` — 130 testes aprovados
- `npm run check` — dry-run do Cloudflare aprovado
- `npm run test:smoke` — fluxo HTTP local aprovado

## Observacao
- distancia geografica real e avaliacao nao foram simuladas: dependem de coordenadas e reputacao, dados ainda nao existentes no produto
